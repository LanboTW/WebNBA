# WebNBA

3D 網頁籃球遊戲（Three.js + TypeScript），目標是 5v5 完整規則與即時連線對戰。

**▶ 線上試玩：<https://lanbotw.github.io/WebNBA/>**（電腦、手機都能玩；GitHub Pages 上沒有連線伺服器，所以只開放對戰電腦、觀戰與投籃練習）

推上 `main` 會自動測試並部署到 GitHub Pages（`.github/workflows/pages.yml`）。之後有了連線伺服器，在 repo 的 Actions 變數設定 `VITE_SERVER_URL=wss://…/ws`，線上對戰就會打開。

## 開發

```bash
npm install
npm run dev        # http://localhost:5173
npm run server     # 連線對戰伺服器（port 8787），開發時頁面經由 /ws 連過去
npm test           # 規則、模擬、AI 整場測試與連線伺服器測試
npm run typecheck
```

`npm start` 會先建置前端，再用同一個程序同時提供網頁與連線（`PORT` 環境變數可改 port）。前端若部署在別處，建置時設定 `VITE_SERVER_URL=wss://你的伺服器/ws`。

## 結構

- `shared/` 遊戲模擬（固定 30Hz tick、可重現亂數），單機與伺服器共用
  - `sim.ts` 每個 tick 的流程；`players.ts` 移動／投籃／灌籃／傳球／抄截／碰撞犯規；`ball.ts` 球的物理、接球、籃板、火鍋；`rules.ts` 時鐘、球權、發球、出界、違例、節次、暫停；`fouls.ts` 犯規、加罰、罰球；`bench.ts` 體力與換人；`ai.ts` 進攻與防守 AI
  - `data/roster.json` 名單（30 隊 × 8 人，可替換）
- `client/` Three.js 畫面、選單、輸入、HUD、數據表、音效
  - `net.ts` 連線協定、狀態編碼、斷線交給 AI
- `server/` 權威伺服器（Node + ws）：房間、30Hz 模擬、20Hz 快照
- `tools/`（第 6 階段）名單更新工具

## 模式

- **對戰電腦**：你控制主隊，隊友與對手由 AI 操控
- **電腦對戰（觀戰）**：兩隊都是 AI
- **投籃練習**：單人、沒有時鐘
- **線上對戰**：和朋友各控一隊，其餘由 AI 操控

## 線上對戰

1. 模式選「線上對戰」，選好隊伍、填暱稱，按「建立房間」。房主是主隊，每節長度、難度和規則開關用主選單的設定。
2. 把 6 碼房間代碼或「複製連結」的網址傳給朋友。朋友開連結（或輸入代碼）、選隊後按「加入房間」。雙方可以選同一隊，客隊會穿客場球衣。
3. 兩人都到齊後，房主按「開始比賽」。

- 比賽由伺服器計算；你的操作會先在本機預測，畫面不用等伺服器回應，伺服器的結果到了再平滑修正。
- 斷線時由電腦接手你的隊伍，60 秒內重新整理頁面或網路恢復就會自動回到比賽。超過 60 秒座位會釋出，其他人可以用代碼加入接手。
- 線上比賽不會暫停：Esc 只打開數據與換人畫面，比賽照常進行。要停下來請用暫停（T）。
- 右上角顯示房間代碼、延遲，以及對手的連線狀態。

| --- | --- | --- |
| 移動 | WASD／方向鍵 | 左搖桿 |
| 加速 | Shift | RT／RB |
| 投籃（按住，在綠區放開） | J | X／□ |
| 灌籃（靠近籃框） | Shift＋J | RT＋X |
| 傳給指定隊友（頭上號碼） | 1–4 | |
| 傳球（進攻）／抄截（防守） | K | A／× |
| 跳：蓋火鍋、搶籃板（持球起跳＝收球） | 空白鍵 | Y／△ |
| 加強防守（按住） | U | LT／L2 |
| 切換球員（防守） | L | LB／L1 |
| 叫暫停（死球或我方持球時；暫停中再按一次＝繼續） | T | Back／Share |
| 暫停遊戲＋數據＋換人 | Esc | |
| 切換視角（轉播／後場） | C | |

**手機／平板**：左半邊畫面按住拖曳是虛擬搖桿（推到底＝加速），右下三顆大按鈕的功能跟著攻守切換：

| 按鈕 | 進攻 | 防守 |
| --- | --- | --- |
| 大顆 | 投籃（按住，綠區放開；加速中靠近籃框＝灌籃） | 緊迫防守（按住） |
| 中顆 | 傳球 | 抄截 |
| 小顆 | 跳 | 蓋帽 |

直接點隊友頭上的號碼就會傳給他。左上方的小按鈕是換人、叫暫停、切換視角和選單（數據／換人）。開始比賽時會嘗試全螢幕並鎖定橫向，直放時會提示橫放。觸控筆電第一次碰螢幕時也會出現這組按鈕。

持球時隊友頭上會顯示 1–4 號，按數字鍵直接傳給他。按 K 則傳給方向鍵那一側的隊友（沒按方向就傳最近的人），橘色標亮的就是這次會接球的人。

持球時可以起跳，空中也能傳球；但持球起跳就算收球，落地後只能原地轉身、傳球或投籃，不能再運球（避免二次運球）。

**視角**：轉播視角是傳統的側面視角；後場視角會站在進攻方身後、朝他們進攻的籃框看，球權轉換時鏡頭會繞過來。後場視角下方向鍵跟著畫面走（上＝往畫面深處）。主選單可以選預設視角，比賽中按 C 切換。

你控制的球員腳下有體力條（綠→黃→紅）。

選隊畫面會顯示球員評分（13 項能力值平均）與球隊評分（先發五人評分平均）。

靠近籃框（2.6 公尺內）按住 Shift 出手會灌籃；只有身高加彈跳摸得到籃框的球員能灌，其他人會改成上籃。灌進後會掛在籃框上一下。

按住加強防守時，球員會自動貼到持球者（或你盯的人）與籃框之間並跟著滑步，方向鍵可微調；對手投籃較難進、抄截機率提高，持球者移動變慢。控制圈會變紅色。代價是比較耗體力，也比較容易被吹犯規。

## 規則

主選單可以分別關掉三組規則：

- **犯規與罰球**：投籃犯規（進算加罰，沒進罰 2 或 3 球）、打手、阻擋與進攻犯規（防守者站定、面向持球者、不在合理衝撞區內才算撞人）、加強防守時的非法接觸。每節第 5 次團隊犯規起加罰（延長賽第 4 次）；每節最後 2 分鐘（依節長等比例縮短）第 2 次犯規也加罰。個人 6 犯離場。罰球用同一個投籃計量條，最後一罰出手後其他人才能搶位置。
- **違例**：進攻 3 秒、防守 3 秒（技術犯規，罰 1 球後進攻方發球）、8 秒過半場、回場、5 秒發球。
- **體力與換人**：上場會掉體力（衝刺、加強防守掉更快），體力低會跑得慢、投得差、跳得低；替補在板凳上恢復。死球時會自動換下太累或犯滿的球員，電腦教練也會把休息好的主力換回來。你也可以在 Esc 或暫停畫面點場上球員、再點替補，下次死球就會換。

每隊每場 5 次暫停（延長賽各加 1 次），每次最多 30 秒。第 4 節與延長賽最後 2 分鐘，持球方喊暫停後改在前場發球。對手打出 8 分以上的攻勢時，電腦會喊暫停。

走步與二次運球不是吹判，而是做不出來：持球起跳落地後，系統只允許轉身、傳球或投籃。

## 名單

`shared/data/roster.json` 是 2025-26 開季名單的手動快照，每位球員格式為
`[名字, 背號, 身高(m), 位置, [能力值…]]`，能力值順序見檔案內的 `ratingKeys`。
部分賽季中交易可能尚未反映，第 6 階段的名單更新工具會處理。
