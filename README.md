# WebNBA

3D 網頁籃球遊戲（Three.js + TypeScript），目標是 5v5 完整規則與即時連線對戰。

## 開發

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # shared/ 規則、模擬與 AI 整場測試
npm run typecheck
```

## 結構

- `shared/` 遊戲模擬（固定 30Hz tick、可重現亂數），單機與伺服器共用
  - `sim.ts` 每個 tick 的流程；`players.ts` 移動／投籃／傳球／抄截；`ball.ts` 球的物理、接球、籃板、火鍋；`rules.ts` 時鐘、球權、發球、出界、節次；`ai.ts` 進攻與防守 AI
  - `data/roster.json` 名單（30 隊 × 8 人，可替換）
- `client/` Three.js 畫面、選單、輸入、HUD、數據表、音效
- `server/`（第 4 階段）權威伺服器
- `tools/`（第 6 階段）名單更新工具

## 模式

- **對戰電腦**：你控制主隊，隊友與對手由 AI 操控
- **電腦對戰（觀戰）**：兩隊都是 AI
- **投籃練習**：單人、沒有時鐘

## 操作

| 動作 | 鍵盤 | 手把 |
| --- | --- | --- |
| 移動 | WASD／方向鍵 | 左搖桿 |
| 加速 | Shift | RT／RB |
| 投籃（按住，在綠區放開） | J | X／□ |
| 傳給指定隊友（頭上號碼） | 1–4 | |
| 傳球（進攻）／抄截（防守） | K | A／× |
| 跳：蓋火鍋、搶籃板 | 空白鍵 | Y／△ |
| 切換球員（防守） | L | LB／L1 |
| 暫停＋數據 | Esc | |

持球時隊友頭上會顯示 1–4 號，按數字鍵直接傳給他。按 K 則傳給方向鍵那一側的隊友（沒按方向就傳最空檔的人），橘色標亮的就是這次會接球的人。

## 名單

`shared/data/roster.json` 是 2025-26 開季名單的手動快照，每位球員格式為
`[名字, 背號, 身高(m), 位置, [能力值…]]`，能力值順序見檔案內的 `ratingKeys`。
部分賽季中交易可能尚未反映，第 6 階段的名單更新工具會處理。
